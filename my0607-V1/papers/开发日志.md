# 第一部分：工作流1 — 框架理解

## 1.1 simpledrop2d.cpp 执行流分析

### 主循环执行顺序

```
1. VELOCITY 场写入 (Taylor-Green 涡旋)
   → VELOCITY.Communicate()
2. PHI = sum(pop[0..8]) (零阶矩，从 D2Q9 分布函数重建相场)
   → PHI.Communicate()
3. ApplyCellDynamics<DropletNormalTask> (ff::FF2D → 计算 GRAD + NORMAL)
   → NORMAL.Communicate()
4. ApplyCellDynamics<DropletCollisionTask> (BGKSource → 碰撞 + 源项)
5. PeriodicBoundary.Apply() (周期边界 + MPI 跨节点)
6. Stream() (传播：把每个方向的粒子群沿 c_k 方向移位)
7. NormalCommunicate() (块间幽灵层同步)
```

### 字段依赖链

```
POP → PHI → GRAD → NORMAL → BGKSource(POP + NORMAL) → Stream(POP)
```

### 6 个 Cell 字段 (TypePack)

| 字段 | 类型 | 用途 |
|------|------|------|
| `PHI<T>` | 标量 | 相场序参量 (0 = 外侧, 1 = 内侧) |
| `POP<T,9>` | 9 分量分布函数 | D2Q9 粒子群 (CyclicArray 高速移位) |
| `VELOCITY<T,2>` | 2D 矢量 | 平流速度 (Taylor-Green 预设) |
| `GRAD<T,2>` | 2D 矢量 | 相场梯度 (FF2D 计算) |
| `NORMAL<T,2>` | 2D 矢量 | 界面法向量 (GRAD 归一化) |
| `INTERFACEWIDTH<T>` | 标量 | 界面宽度 (常数，初始化时设一次) |

### 块几何初始化流程

```

  → CreateBlocks(1, mpi().getSize())           // 每进程 1 块
```

## 1.2 TaskSelector 模板机制 (`src/utils/tmp.h`)

### 核心调用链路

```
BlockLattice::ApplyCellDynamics<CELLDYNAMICS>(flagarr)
  → 遍历所有 voxel，读 FLAG 字段
  → CELLDYNAMICS::Execute(flagarr[id], cell)
    → TaskSelector::Execute(flag, cell)
      → SelectTask::execute(flag, cell)
        → 编译期 if-else 链 (递归展开 int_sequence<keys...>)
        → util::isFlag(flag, KeyValue) — 位与匹配
        → TUPLE::get<KeyValue>::type::apply(cell)
```

### 关键模板

**Key_TypePair** (`tmp.h:175-182`)：
```cpp
template <auto KeyValue, typename Type>
struct Key_TypePair {
  static constexpr auto key = KeyValue;  // e.g. uint8_t(2) = BulkFlag
  using type = Type;                      // e.g. ff::FF2D<CELL>
};
```

**TupleWrapper** (`tmp.h:184-208`)：封装 `std::tuple<Key_TypePair...>` 并提供按键查找和 `make_key_sequence`。

**int_sequence** (`tmp.h:150-160`)：编译期值序列，用于生成递归 if-else 链。

**SelectTask** (`tmp.h:211-220`)：
```cpp
template <typename TUPLE, typename FlagType, typename CELL, typename KeySequence>
struct SelectTask {
  static void execute(FlagType flag, CELL &cell) {
    if (util::isFlag(flag, KeySequence::first)) {
      TUPLE::template get<KeySequence::first>::type::apply(cell);
    } else if constexpr (KeySequence::rest_size > 0) {
      SelectTask<TUPLE, FlagType, CELL, typename KeySequence::rest>::execute(flag, cell);
    }
  }
};
```

**TaskSelector** (`tmp.h:222-228`)：入口点，从 TupleWrapper 提取 key_sequence 传给 SelectTask。

两个并行系统：

| 系统 | 位置 | 用法 |
|------|------|------|
| `tmp::TaskSelector` | `tmp.h:222-228` (tmp:: 命名空间) | 基于 `TupleWrapper<Key_TypePair...>` |
| `TaskSelector` | `tmp.h:284-289` (全局命名空间) | 基于直接可变参数 `Tasks...` (无 TupleWrapper) |

## 2.3 接口设计

### equilibrium::FirstOrder<CELL>

```cpp
namespace equilibrium {

template <typename CELL>
struct FirstOrder {
  using T = typename CELL::FloatType;
  using LatSet = typename CELL::LatticeSet;

  // f_eq(k) = w_k * phi * (1 + c_k·u / cs²)
  static T get(CELL& cell, unsigned int k) {
    const T phi = cell.template get<PHI<T>>();
    const auto& u = cell.template get<VELOCITY<T, LatSet::d>>();
    T cu = latset::c<LatSet>(k) * u;
    return latset::w<LatSet>(k) * phi * (T(1) + LatSet::InvCs2 * cu);
  }
};
```

**设计决策**：`get()` 接受 `cell&` 而非离散参数 `(k, phi, u)`。
- `simpledrop2d.cpp:270` 只有 3 模板参数（Equilibrium, SourceField, bool），没有独立的"密度场类型"参数
- 让 equilibrium 内部自行获取场，BGKSource 模板签名保持简洁
- FirstOrder 总是取 `PHI<T>`，SecondOrder 总是取 `RHO<T>` — 职责边界清晰
- 验证：与 `simpledrop2d.cpp:248-250` 初始化代码 `latset::w(k)*phi*(1+InvCs2*c*dv)` 完全一致

### equilibrium::SecondOrder<CELL>

```cpp
template <typename CELL>
struct SecondOrder {
  using T = typename CELL::FloatType;
  using LatSet = typename CELL::LatticeSet;

  // g_eq(k) = w_k * rho * (1 + 3(c·u) + 4.5(c·u)² - 1.5u²)
  static T get(CELL& cell, unsigned int k) {
    const T rho = cell.template get<RHO<T>>();
    const auto& u = cell.template get<VELOCITY<T, LatSet::d>>();
    T cu = latset::c<LatSet>(k) * u;
    T u2 = u * u;
    return latset::w<LatSet>(k) * rho
           * (T(1) + T(3) * cu + T(4.5) * cu * cu - T(1.5) * u2);
  }
};

}  // namespace equilibrium
```

**当前限制**：系数硬编码为 D2Q9 值 (cs²=1/3, InvCs²=3)，后续可通过 `LatSet::cs2` 泛化。

### collision::BGKSource<Equilibrium, SourceField, hasSource>

```cpp
namespace collision {

template <typename Equilibrium, typename SourceField, bool hasSource>
struct BGKSource {
  using T = typename Equilibrium::T;
  using LatSet = typename Equilibrium::LatSet;

  static void apply(CELL& cell) {
    const T omega = cell.getOmega();

    if constexpr (hasSource) {
      const T omega_half = T(0.5) * omega;
      const auto& source = cell.template get<SourceField>();
      for (unsigned int k = 0; k < LatSet::q; ++k) {
        T feq = Equilibrium::get(cell, k);
        T f_old = cell[k];
        // S_k = (1 - 0.5*omega) * w_k * (c_k · n)
        T Sk = (T(1) - omega_half)
               * latset::w<LatSet>(k)
               * (latset::c<LatSet>(k) * source);
        cell[k] = f_old - omega * (f_old - feq) + Sk;
      }
    } else {
      for (unsigned int k = 0; k < LatSet::q; ++k) {
        T feq = Equilibrium::get(cell, k);
        cell[k] = cell[k] - omega * (cell[k] - feq);
      }
    }
  }
};

}  // namespace collision
```

**源项公式**：`S_k = (1 - 0.5ω) · w_k · (c_k · n)`，其中 `n` 来自 `SourceField`。
- 来自 Guo 力项格式 (Guo et al., 2002)，是 LBM 施加体积力的标准二阶精度方案
- `(1 - 0.5ω)` 因子是离散化校正项

**CELL 类型推断**：从 `Equilibrium::get(CELL&, unsigned int)` 的第一个参数自动推断，`BGKSource` 不需要显式 CELL 模板参数。

## 2.5 验收标准

1. `equilibrium::FirstOrder<CELL>::get(cell, k)` 返回 `w_k·φ·(1 + c_k·u/cs²)`
2. `equilibrium::SecondOrder<CELL>::get(cell, k)` 返回标准 D2Q9 二阶平衡态
3. `BGKSource::apply(cell)` hasSource=false 时执行纯 BGK：`f_k ← f_k - ω(f_k - f_k^eq)`
4. `BGKSource::apply(cell)` hasSource=true 时额外加源项：`f_k += (1-0.5ω)·w_k·(c_k·n)`
5. `simpledrop2d.cpp:270-275` 的模板实例化可编译通过
6. `cell_dynamics.h:4` 的 `#include "lbm/collision.h"` 能解析到新文件

## 2.6 风险

| 风险 | 可能性 | 缓解 |
|------|--------|------|
| CELL 类型从 Equilibrium::get(cell) 推断失败 | 低 | 编译器从实际实参 cell 推断 CELL，C++17 CTAD 足够 |
| RHO 不在 simpledrop2d FIELDS 中 → SecondOrder 编译失败 | 中 | 第一步只测 FirstOrder；SecondOrder 等流场格子建立后再启用 |
| 块级 getOmega() 未来需改为 per-cell OMEGA<T> | 低 (后续) | 接口预留：`cell.getOmega()` 可替换为 `cell.template get<OMEGA<T>>()` |
| simpledrop2d 还依赖 ff::FF2D (已删除) → 无法全链路编译 | 高 | 本阶段只验证 collision.h 被 cell_dynamics.h 加载可实例化；全链路等 pf/ 全部完成后 |
